# 重汽三码合一程序

这是按《重汽三码合一程序技术协议》生成的第一版可运行程序。

当前版本功能：

- 型号维护：型号、9 位条码号、1 位固定码。
- 自动生成 22 位码：9 位条码号 + 1 位固定码 + 8 位日期 + 4 位流水号。
- 数据库防重：22 位码唯一约束，流水号按型号和日期递增。
- 标签打印：生成 Zebra ZPL，默认保存到 `output/labels`。
- 激光打码：默认保存下发命令到 `output/laser`。
- 当前重新打印：不生成新码，标签标注 `REPRINT n`，数据库记录次数。
- 数据查询和 CSV 导出。
- 设备通讯日志、报警日志。

## 运行

双击：

```bat
run.bat
```

或在当前目录执行：

```bat
python src\main.py
```

首次运行会自动创建：

- `data/sanma.db`
- `output/labels`
- `output/laser`

并自动加入一个示例型号，方便先试流程。

## 现场切换设备通讯

默认配置为文件模拟模式，便于未接设备时测试业务流程：

```json
"printer": {
  "mode": "file"
},
"laser": {
  "mode": "file"
}
```

打印机可切换：

- `file`：输出 ZPL 文件。
- `tcp`：通过网口 9100 端口发送 ZPL。
- `raw_path`：写入 Windows 原始设备路径或共享打印机路径。

激光可切换：

- `file`：输出激光下发命令文件。
- `tcp`：通过 TCP 发送指令。
- `none`：跳过激光下发，仅测试打印和数据库。

现场确认激光设备协议后，只需要调整 `config.json` 和 `src/devices.py` 中的适配器。

## 关键规则

- 22 位码只由程序生成一次。
- 数据库先预占并设置唯一约束。
- 标签二维码、条形码、激光打码均使用同一个 `code22`。
- 打印或激光失败时，该码保留异常记录，不自动复用。
- 重新打印只针对当前完成记录，不生成新码。
