## 2. 启动程序

**推荐方式：双击 `run.bat`**，在交互菜单选择：
- `[1]` 联机前自检 — 检查配置/串口/打印/TXT 目录/PLC

```powershell
python src\main.py --init-db     # 首次初始化
```

## 3. 检查清单

### 3.1 扫码枪 (COM3)

> 当前状态: 串口参数已配置在 `config.json` → `scanner.serial`，但 **尚未接入实际扫码业务路径**。
> 自检脚本可以验证 COM3 是否存在，但程序主流程暂不读取扫码枪。

```powershell
# 检查 COM3 是否存在
mode COM3

# 用 Python 测试串口（需 pip install pyserial）
python -c "import serial; s=serial.Serial('COM3',9600,timeout=1); print('COM3 OK'); s.close()"
```

如果报错 `could not open port`:
1. 检查扫码枪 USB 线是否插好
2. 设备管理器 → 端口 → 确认 COM 口号
3. 如果不是 COM3，修改 `config.json` → `scanner.serial.port`

### 3.2 打印机 (USB)

> 当前默认模式 `file`：ZPL 文件输出到 `output/labels/`。
> 切换到 USB 直接打印需改 `printer.mode` 为 `usb`。

```powershell
# 查看打印机名称和端口号（记下 Zebra 对应的 PortName，通常为 USB001）
wmic printer get Name,PortName
```

切换到 USB 打印步骤（候选方案，待现场验证）:
1. `wmic printer get Name,PortName` → 记下 Zebra 的 PortName（如 `USB001`）
2. 填入 `config.json` → `printer.portName: "USB001"`
3. 修改 `printer.mode` 从 `file` 为 `usb`
4. 如 USB 直写不稳定，可改用 `raw_path` 模式（需先共享打印机）或保持 `file` 模式（输出 ZPL 文件）

> 注意：`usb` 模式通过 `\\.\USB001` 设备路径写入，此方法为候选实现，待现场 Zebra 打印机实测确认。
